## How it fits together

```
winshelld          native daemon: tracks windows, runs services (audio, wifi, media, …),
   │                hotkeys, config; JSON over a named pipe
   ├── winshell-host   draws the surfaces (WebView2 windows: bars, popups, widgets)
   │      └── your pages  use @winshell/sdk
   └── winshellctl     the command line client
```

Services only run while something subscribes to them, so an idle winshell costs next to nothing.
