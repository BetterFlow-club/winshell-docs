# create-winshell-shell

Start a [winshell](https://betterflow-club.github.io/winshell-docs/) shell:
Vite + TypeScript + `@winshell/sdk`, with a top bar (focused window, clock,
volume) and a calendar popup.

```bash
npm create winshell-shell my-shell
cd my-shell
npm install
npm run deploy   # build, copy into winshell's shells folder
npm run try      # show it now, without editing your config
```

The project's README covers hot reload and keeping the shell in your
config.
